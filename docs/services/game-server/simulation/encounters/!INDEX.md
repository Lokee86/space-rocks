# Encounters

Parent index: [Game Server Simulation](../!INDEX.md)

Encounter spawning and lifecycle documentation lives here.

## Ownership

This folder owns current game-server documentation for encounter spawn profiles, spawn scheduling, origin metadata, population accounting, and post-spawn retirement decisions.

## Does Not Belong

- Player spawn placement.
- Damage or destruction rules.
- Room membership.
- Client presentation.
- Mission or campaign planning.
